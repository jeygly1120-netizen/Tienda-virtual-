# Jeygly Store Animada

Archivos:
- index.html
- style.css
- script.js
- images/

Características:
- Diseño moderno y responsive
- Animaciones
- Catálogo y categorías
- Buscador
- Carrito
- Pedido por WhatsApp
- Personalización de nombre, subtítulo, WhatsApp, moneda y colores
- Modo oscuro
- Guarda configuración y carrito en el navegador

Para GitHub Pages:
1. Sube los archivos al repositorio.
2. Asegúrate de que `index.html` esté en la raíz.
3. Activa GitHub Pages desde Settings > Pages.
4. La tienda funcionará como sitio estático.

Importante: los cambios del panel de personalización se guardan solamente en el navegador donde se realizan. Para que los cambios se publiquen para todos los visitantes se necesita actualizar los archivos o conectar una base de datos/backend.
